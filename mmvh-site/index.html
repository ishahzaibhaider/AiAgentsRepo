How it works

One agent decides.
Code enforces.

The model handles language. It cannot touch the calendar except through four tools, and each tool re-checks every rule itself.

01

Message in

Form, chat or webhook. A request ID and free text are all it needs.

02

Replay check

A completed request sent again with the same ID returns the stored result. Nothing new is created.

03

Agent decides

Claude picks one: book, cancel, reschedule, check, ask for details, hand off, or refuse.

04

Tools enforce

Rules are read from the Config tab and checked against the live calendar on every call.

05

Truth guard

The tool's result replaces the model's words. A success claim with no tool result becomes an error.

06

Log and reply

Every request lands in CallLog. Handoffs and failures also alert staff on Discord.
